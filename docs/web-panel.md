# Как проверить новую панель VTASK

## Обновление существующей установки Ирины

1. Остановите старый сервер в Terminal: Ctrl+C, предварительно завершив активную запись.
2. Сохраните копию каталога с текущей БД и аудио. Если запускали с рекомендованным `--db`, это `$HOME/Library/Application Support/VTracker`.
3. Сохраните `VTASK-web-panel-source.zip` в «Загрузки». Архив уже содержит верхний каталог `VTaskerLD`, поэтому распакуйте его **в родительскую папку VTASK**, с заменой исходников. В архиве нет вашей БД, аудио, моделей и `.build`.
4. Выполните:

```sh
mkdir -p "$HOME/Projects/VTASK"
ditto -x -k "$HOME/Downloads/VTASK-web-panel-source.zip" "$HOME/Projects/VTASK"
cd "$HOME/Projects/VTASK/VTaskerLD"
bash scripts/setup-macos.sh --with-microphone
bash scripts/start-macos.sh --db "$HOME/Library/Application Support/VTracker/data.sqlite3"
```

Если раньше использовался другой `--db`, сохраните именно тот путь, иначе откроется новое пустое хранилище. Новая версия автоматически добавляет таблицы без удаления прежних встреч. Модели и библиотеки повторно используются после проверки checksums.

Откройте http://127.0.0.1:8765 и обновите страницу. Теперь первый раздел — **Обзор**. Устанавливать Node, npm, React или дополнительные расширения браузера не нужно.

## Проверка за один короткий разговор

1. Нажмите **«Новая встреча»**. Укажите название; проект и участников можно пока не выбирать. Сохраните форму.
2. В карточке нажмите **«Начать запись»** (если нет моделей — «Начать только запись»). Предупредите участников, разрешите микрофон в macOS.
3. Дождитесь надписи **«Запись»**. Вверху видны длительность, уровень и время сохранённого аудио. Пауза доступна после обновления адаптера.
4. Произнесите несколько фраз. Можно перейти в другой раздел: полоса записи останется видна. Пауза входит в общий лимит сессии.
5. Нажмите **«Завершить и сохранить»**. Сначала завершится запись, затем запустится распознавание — эти состояния отображаются отдельно. Автообработка включена по умолчанию и изменяется в настройках.
6. Откройте карточку встречи: аудио и текст появятся без ввода ID. Если модель не настроена или дала ошибку, запись остаётся доступной.
7. Нажмите временную метку для прослушивания фрагмента, попробуйте поиск по тексту, исправление текста и назначение говорящего.
8. Нажмите «Предложить поручение» у реплики. В форме можно выбрать создание задачи, изменение существующей задачи или решение. Новая задача не возникнет до подтверждения.
9. Откройте **«На подтверждение»**, проверьте проект, текст, ответственного и срок. Неоднозначные поля можно оставить пустыми. Нажмите «Подтвердить».
10. Откройте задачу в списке или пайплайне, измените статус. Завершённая задача исчезнет из текущих и просроченных счётчиков.

Для готовой записи используйте **«Импортировать аудио»** внутри встречи. Поддержаны WAV и преобразование M4A/MP3/AAC/FLAC через FFmpeg. Затем нажмите «Распознать запись». Экспорт TXT/JSON доступен рядом с транскриптом.

## Демо без микрофона

Кнопка **«Посмотреть демо»** внизу боковой панели открывает отдельные данные: 3 проекта, 15 задач, 3 встречи, предложения всех типов. Это не ваши реальные записи. Изменения демо сохраняются; повторное открытие не сбрасывает набор. «Мои реальные данные» возвращает исходные встречи.

## Задачи и проекты

- Щёлкните строку/карточку для открытия инспектора. На узком экране он становится отдельным экраном с кнопкой «Назад».
- Сохранение явное. При уходе с изменениями доступны «Сохранить», «Не сохранять», «Остаться».
- Фильтры разных типов объединяются И; несколько значений внутри одного типа — ИЛИ. В «Все фильтры» можно выбрать несколько проектов, статусов, ответственных и сроков.
- Переключение «Список / Пайплайн» сохраняет выборку. Именованные выборки сохраняются отдельной кнопкой.
- Перемещение задачи доступно через «Переместить в» на карточке — мышь не обязательна. Разные пайплайны не объединяются по одинаковым названиям.
- Для массового изменения выберите строки, действие и значения. «Отменить» в уведомлении работает, пока задачи не изменились снова.
- Настройки проекта позволяют менять порядок и названия этапов. Удаление занятого этапа требует указания переноса. Финальные системные типы нужны даже при переименовании этапов.

## Что пока не готово

Системный звук, автоматическое узнавание голосов и LLM не запускаются скрыто и не имитируются в реальных встречах. SwiftUI — следующий интерфейс; сейчас используется согласованная с пользователем веб-панель.

Пауза/уровень добавлены в исходники Swift-адаптера. Сборка и реальные разрешения на вашем M5 ещё требуют проверки; в облаке использовался синтетический источник. VoiceOver и Safari здесь не проверялись. При ошибке сохраните текст сообщения и название шага, на котором она появилась.


## Выбор модели распознавания

В настройках раздел «Модель распознавания» переключает локальный Whisper и облачный API. Изменения применяются со следующей обработки, без перезапуска сервера. Локальные модели выбираются из каталога инструментов; можно указать полный путь к своему Whisper GGML. По умолчанию запуск предпочитает установленную large-v3-turbo-q5_0.

Облачный режим поддерживает HTTPS multipart API /audio/transcriptions с Bearer-ключом и ответом JSON (text) или verbose_json (segments). Укажите полный адрес, имя модели, формат и ключ. Ключ хранится только в памяти сервера, после перезапуска введите его снова; при смене адреса старый ключ сбрасывается. Аудио отправляется при обработке, включая включённую автообработку; до 24 МБ WAV. Без сегментов с таймкодами текст показывается единым блоком, локальная диаризация к нему не применяется. У других API-протоколов отдельных адаптеров пока нет.

Облачный адаптер проверен на подставных ответах без сетевых запросов: python3 tests/cloud_adapter.py. Проверка реального сервиса требует ключа пользователя и доступного тарифа.


## Выбор микрофона

В настройках выберите устройство, сохраните его и нажмите «Проверить 5 секунд». Проверка включает микрофон без сохранения записи. Для новых записей используется сохранённый UID; можно выбрать другой микрофон в карточке встречи перед стартом. Список обновляется отдельной кнопкой. Смена устройства во время записи запрещена. При отключённом выбранном устройстве приложение сообщает ошибку, не переключаясь незаметно на встроенный микрофон.

Фактический UID и название доступны в `fragments[].device` JSON-экспорта. Существующие записи без этих метаданных остаются доступны.


## Live STT

Выберите локальную модель и режим Live в настройках или в карточке встречи («Источники и режим записи»). После старта ниже аудио появится отдельный предварительный текст. У каждого фрагмента есть таймкоды текущей сессии; текст может быть неполным на границах пятесекундных WAV. Назначать людей, исправлять текст и создавать поручения следует по итоговому транскрипту.

После остановки текущий Live-процесс завершается, затем при включённой автообработке выполняется полный проход. Предварительные результаты остаются в раскрывающемся блоке; итоговый транскрипт хранится отдельной версией. При отключённой автообработке нажмите «Распознать запись».

При накоплении очереди, двух медленных фрагментах или ошибке модели Live приостанавливается до окончания встречи. Аудио продолжает сохраняться. После аварии остановите прежние процессы, восстановите запись штатной кнопкой, затем явно восстановите Live-очередь. Результаты и аудио не удаляются. Облачный Live и предварительное определение говорящих пока не реализованы.


## Продолжение и голосовые образцы

После остановки и завершения обработки в карточке доступно «Продолжить встречу». Аудио всех частей остаётся в общей временной шкале. Старый транскрипт сохраняется и показывает предупреждение, пока новая часть не включена в полную обработку.

В карточке участника можно загрузить образец голоса (6–60 секунд, до 16 МБ). Требуются отдельные подтверждения согласия участника и записи одного голоса. Приложение проверяет формат, длительность, уровень и перегрузку, затем создаёт локальный голосовой вектор в фоне. Это техническая проверка, она не доказывает, что в файле речь одного человека. Несколько образцов создают новые версии профиля одной модели; данные разных моделей не смешиваются. Сопоставление с профилями предлагает имена для ручного подтверждения; автоматическое применение имени не выполняется.

Кнопка удаления удаляет сохранённые в приложении образцы, версии профилей и задания и отмечает отзыв согласий; сам участник, назначения в транскриптах и история встреч остаются. Резервные копии управляются отдельно. Для прерванных заданий доступны подтверждаемое восстановление и повторная попытка.


## Регистрация из голоса и сопоставление участников

У реплики с одним голосом нажмите «Создать профиль голоса». Если речь нескольких людей попала в один текстовый сегмент, используйте раскрывающийся список «Голоса встречи» над транскриптом. В нём также можно вручную назначить имя голосу целиком.

В форме регистрации показаны отобранные участки и их длительность. Участки пересечения голосов удаляются, выбираются наиболее длинные фрагменты общей длительностью до 30 с; меньше 6 с не принимается. Кнопки с таймкодами запускают исходное аудио в плеере. Прослушайте участки, выберите человека и подтвердите согласие и один голос. Эта проверка опирается на диаризацию и ваше подтверждение; она не доказывает личность.

«Сопоставить голоса с профилями» ставит отдельное локальное задание после завершённого распознавания. Подсказки появляются в списке голосов и рядом с подходящими репликами. «Подтвердить имя» действует на весь голос только в выбранной версии встречи; «Оставить неизвестным» фиксирует ручное решение. Ручные назначения и исправления реплик не перезаписываются.

Настройки → «Сопоставление говорящих»: включение для следующих обработок, порог косинусного сходства и минимальный отрыв от второго кандидата. Сходство не является вероятностью личности, начальные пороги не откалиброваны на ваших голосах. Низкий балл, сходные кандидаты, несовместимая версия модели, недостаточная или некачественная речь оставляют имя неизвестным с пояснением. При включении режима уже завершённые встречи автоматически не обрабатываются — для них используйте кнопку в карточке.

Ошибки сопоставления не удаляют итоговый транскрипт. Для ошибок есть повторная попытка; после аварии доступно восстановление голосовой очереди с подтверждением остановки прежних процессов. Удаление профиля удаляет его неподтверждённые подсказки, но сохраняет ручные назначения имён и историю.
