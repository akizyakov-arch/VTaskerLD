# Состояние MVP по ТЗ

Требования к нативному интерфейсу, границы SwiftUI и Rust и критерии приёмки переноса вынесены в [ТЗ для macOS](macos-requirements.md).

Источник требований: `../../read.md`, версия 1.0. Обновлено 2 ноября 2026.

Качество large-v3-turbo-q5_0 на базовой речи пользователь принял для текущего этапа. Дизайн, специальный словарь и голосовые команды отложены по указанию пользователя. Облачный API — добавленное пользователем расширение; реальный запрос с пользовательским ключом пока не проверен.

## Порядок дальнейшей работы

1. Завершить аппаратную проверку выбранного микрофона, ошибки отключения и длительной записи.
2. Аппаратная приёмка Live STT на русской речи, длительном разговоре и паузах. Реализованы отдельная очередь, предварительные результаты, приоритет записи, ограничение очереди и финальная обработка.
3. Следующий шаг голосовых профилей: аппаратная приёмка записи трёх фраз и калибровка сопоставления на русской речи нескольких участников. Регистрация из файла/встречи, исключение пересечений, пороги неизвестного, ручное подтверждение и исправление реализованы. Функциональная проверка реальных эмбеддингов не заменяет измерение точности идентификации.
4. Управление нагрузкой и измерения на M5: RAM, задержка, WER/DER, длительная запись не менее двух часов.
5. Резервное копирование, сроки хранения и защита чувствительных данных по разделу 9 ТЗ.

Не считать реализованную функцию аппаратно принятой без соответствующего сценария проверки. Веб-панель и задачи уже существуют по ранее выбранному порядку; новые функции MVP добавляются в общее ядро.

## Продолжение встречи

Завершённую встречу можно продолжить в той же карточке. Новые аудиособытия добавляются после прежних, включая импортированные записи. Старый транскрипт помечается как требующий обновления, исходное аудио и версии моделей сохраняются. Миграция 011 фиксирует единый порядок аудио для плеера, STT и Live.
