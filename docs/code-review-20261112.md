# Анализ и рефакторинг VTASK от 12 ноября 2026

Перед изменениями сохранены VTASK-app-20261112-161916.zip и VTASK-source-20261112-161916-before-refactor.zip в родительской папке VTASK. Для обоих архивов проверена целостность ZIP и сохранена SHA-256. Архив приложения содержит текущую локальную сборку, которая использует установленные на этом Mac модели и инструменты. Для чистого Mac требуется автономный дистрибутив с зависимостями.

Проверены структура SwiftUI-приложения, слой доступа к ядру, запуск распознавания, подготовка аудио, обновление схемы SQLite и существующие автоматические проверки. Clippy до изменений прошёл без предупреждений.

## Выполненные изменения

- Файл VTASKApp.swift размером 2145 строк разделён на WorkspaceModels.swift, WorkspaceModel.swift, Transcript.swift, MeetingTranscript.swift, WorkspaceView.swift и точку входа VTASKApp.swift. Содержимое деклараций и методов сверено с архивом побайтно после исключения импортов.
- Управление дочерним процессом распознавания вынесено в src/speech/worker.rs. Экспорт SpeechWorker через прежний модуль сохранён для существующих вызывающих участков.
- Подготовка WAV и настройка Silero VAD объединены в методы SpeechConfig, которые используют Live и итоговое распознавание. Каждый режим передаёт свой прежний тайм-аут и параметры декодирования.
- Цепочка из двадцати условных миграций заменена упорядоченным списком в src/migrations.rs. Версия поддерживаемой схемы вычисляется из длины списка. Обновление выполняется в прежней транзакции. Добавлена явная ошибка для отрицательной версии схемы.

## Оставшиеся ограничения

WorkspaceView.swift и AssistantSearch.swift всё ещё содержат большие объёмы логики представления и обработки команд. Их дальнейшее разделение требует проверки отдельных пользовательских сценариев, особенно уточняющих команд ассистента.

Ранее выявленное дробление голосов Sherpa остаётся функциональной проблемой. На предыдущем полном прогоне двухчасовой записи получено 34 группы при трёх участниках в карточке. Этот рефакторинг сохраняет параметры и поведение распознавания. Повторный длинный прогон моделей в рамках текущей проверки не выполнялся.

Полная ручная проверка экранов, микрофона и голосового диалога после рефакторинга не проводилась. Проверка Swift охватывает сборку и точное сохранение перенесённых деклараций.
