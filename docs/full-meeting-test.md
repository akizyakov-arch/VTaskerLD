# Сквозной тест всего совещания

Пятисекундные WAV-файлы — единицы надёжного сохранения аудио, а не законченные реплики. Native-адаптер закрывает WAV, синхронизирует его и публикует готовый фрагмент. Итоговый обработчик нормализует и последовательно объединяет все аудиовхождения встречи в один PCM-файл; затем один раз запускает Whisper на всей дорожке. Реплика может ссылаться сразу на несколько исходных файлов. Это сохраняет контекст на границах хранения. Groq получает итоговые реплики всей встречи (для больших текстов есть отдельное разбиение по объёму, не по пяти секундам).

В сборке с постоянным обработчиком Whisper распознавание идёт блоками примерно по 30 секунд. Новый блок получает до секунды предыдущего аудио для контекста. Реплики, целиком попавшие в эту секунду, отбрасываются по таймкодам, а совпавшие слова на стыке убираются из начала новой реплики. Контекст начинается заново при разрыве аудио или смене сессии записи. После Live-предпросмотра выполняется итоговый проход. При использовании отдельного `whisper-cli` Live обрабатывает сохранённые фрагменты по одному.

## Воспроизводимый реальный тест

`tests/full_meeting.rs` — тест с явным opt-in, не входит в обычный быстрый прогон. Использует свежую тестовую БД, локальный macOS TTS Milena, установленные Whisper/диаризацию и один запрос Groq по искусственному тексту. Не включает микрофон, не читает пользовательские записи и не меняет рабочую БД. Ключ для Groq читает из существующей области Keychain рабочей БД и не записывает его в артефакты. Возможны расходы API по тарифу аккаунта.

Сценарий `tests/fixtures/full_meeting.txt`: законченная планёрка с шестью группами поручений, повторным обсуждением, отменёнными идеями, уже выполненной работой, неназначенным исполнителем и переносом срока с шестого на четвёртое ноября. Последнее поручение появляется в конце встречи. Все персонажи и проект вымышленные. Озвучивается одним голосом: это не тест распознавания нескольких живых говорящих.

Проверки:

- Исходная запись разбивается на пятисекундные файлы, импортируется двумя последовательными сессиями в одну встречу.
- Перед реальным Whisper тестовый адаптер сверяет PCM всей собранной дорожки с исходным WAV по SHA-256. Ровно один вызов итогового распознавателя.
- Текст доходит до конца записи; есть реплики, пересекающие границы файлов; в снимок Groq входят все итоговые реплики.
- В результате присутствуют все шесть групп действий, отменённые/выполненные действия исключены, окончательный срок сметы сохранён, неназначенный исполнитель не выдуман.
- До проверки нет активных задач; подтверждение создаёт одну задачу; повтор анализа возвращает сохранённый результат без дублей. Ручные заметки сохраняются.

Запуск из корня проекта, с новым каталогом артефактов при каждом повторе:

```sh
(
export VTASK_FULL_MEETING_DIR="$(mktemp -d /tmp/vtask-full-meeting.XXXXXX)"
export VTASK_FULL_GROQ=1
export VTASK_REAL_WHISPER_BIN="$HOME/.local/share/vtracker/whisper.cpp/build/bin/whisper-cli"
export VTRACKER_WHISPER_BIN="$PWD/tests/fixtures/full_meeting_whisper.py"
export VTRACKER_WHISPER_MODEL="$HOME/.local/share/vtracker/models/ggml-large-v3-turbo-q5_0.bin"
export VTRACKER_DIARIZATION_BIN="$HOME/.local/share/vtracker/diarization/vtracker-diarize"
export VTRACKER_SEGMENTATION_MODEL="$HOME/.local/share/vtracker/diarization/segmentation.onnx"
export VTRACKER_EMBEDDING_MODEL="$HOME/.local/share/vtracker/diarization/embedding.onnx"
PYTHONPYCACHEPREFIX=/tmp/vtask-pycache cargo test --test full_meeting -- --ignored --nocapture
)
```

Артефакты: `meeting.wav`, `transcript.txt/json`, `analysis_input.json`, `analysis_result.json`, `engine_calls.jsonl`, `report.json`, отдельная `data.sqlite3`. Тест проверяет заданный сценарий, но не измеряет качество шумной записи или точность идентификации людей. Для этого нужен отдельный тест живого разговора с разрешения участников.

## Результат на Mac, 3 ноября 2026

Полная синтетическая запись: 335,535 секунды (5:35,5), 68 файлов, два последовательных сеанса одной встречи. До реального Whisper PCM собранного файла совпал с исходной дорожкой по SHA-256. Итоговый распознаватель вызван один раз; получены 83 реплики, 66 из них пересекают границы исходных файлов.

Whisper с разделением голосов: 145,42 секунды. Groq: 4,22 секунды. Найдены шесть из шести ожидаемых групп поручений; итог — шесть предложений задач. Окончательный срок сметы — 4 ноября, договора — 3 ноября, формы — 5 ноября, отправки доступа — 2 ноября. Для списка клиентов исполнитель и срок остались пустыми. До подтверждения активных задач нет; после подтверждения одной — ровно одна задача. Повтор анализа не дублирует предложения.

Первый прогон выявил лишнюю задачу назначить следующую встречу: модель вывела её из открытого вопроса. Правило уточнено, в проверку добавлен запрет на такое предложение. Второй полный прогон прошёл с шестью задачами.

Замечание ручной проверки: в свободном резюме модель объединила договор и смету в предложение с общим сроком, хотя даты отдельных задач различаются и в карточках верны. Этот тест не доказывает фактическую точность каждой формулировки свободного резюме: его нужно проверять по транскрипту и карточкам. Также не проверены микрофон, комнатный шум, несколько живых голосов и совещания часовой длительности.

Локальные артефакты сохранены в `docs/ui-previews/full-meeting-20261103/` (исключены из Git): аудио, транскрипт, ответ Groq и машинный отчёт.
