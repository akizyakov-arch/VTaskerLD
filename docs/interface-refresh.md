# Обновление интерфейса — 2 ноября 2026

Первая интеграция выбранного прототипа в существующую веб-панель. Стек сохранён: Rust/SQLite, HTML/CSS/JavaScript, Swift для микрофона.

- Основная навигация: Сегодня, Совещания, Задачи, Проекты, На подтверждение; участники и обработка отделены визуально.
- Сегодня использует реальные задачи, очередь подтверждения, проекты и встречи. Есть честные пустые состояния.
- Круг участников и таймер подключены к реальной активной записи. Без событий определения говорящего показан статус «Говорящий определяется». Уровень микрофона не присваивает имена.
- Встреча: Итоги / Транскрипт / Задачи. Источники поручений открывают транскрипт. Сохранены аудиотаймлайн, поиск, исправления, регистрация и сопоставление голосов, экспорт, продолжение записи. Импорт и повторная обработка перенесены в дополнительные действия.
- Темы system/light/dark переключаются из шапки и сохраняются в существующих настройках SQLite.
- Фильтры задач раскрываются отдельно, быстрые выборки и список/доска остаются снаружи.
- Боковая панель ассистента показывает контекст и реальные переходы. Бот, AI и доставка уведомлений не подключены и не имитируются.

Проверки: все 62 Rust-интеграционных теста прошли; синтаксис JavaScript проверен; создание проекта через UI и сохранение после reload проверены на изолированной SQLite. В пользовательской базе проверены список встреч, завершённая встреча, вкладки и существующий транскрипт. Новой записи реального микрофона при этой проверке не выполняли. Исходники и SQLite сохранены в локальных резервных копиях до обновления; схема БД обновлена до версии 14 с отдельной таблицей ручных итогов.

Ограничения: автоматическое резюме отсутствует; ручное резюме и открытые вопросы сохраняются с версиями, автором и историей; подтверждённые решения доступны через предложения из транскрипта. Калибровка голосовых моделей и длительная аппаратная приёмка не относятся к этой визуальной итерации. Интеграционные контракты бота — в docs/assistant-contract.md, их серверная реализация остаётся следующим этапом.

В набор для GitHub включены только исходники, тестовые фикстуры и общая документация. Публикация исходников пока не выполнена: автоматическая проверка требует отдельного подтверждения. Локальная БД, аудио, модели, биометрические данные и скриншоты с реальными встречами исключены.

## Ручные итоги

Кнопка «Добавить итоги» на вкладке «Итоги» сохраняет резюме и открытые вопросы в SQLite. Имя автора определяется текущим «Кто я» в настройках; если оно не задано — «Локальный пользователь». Источник — локальное рабочее пространство. Сервер не принимает подставленное клиентом имя автора. Это локальная идентификация, не авторизация удалённого бота.

Оптимистическая revision защищает от перезаписи из другого окна. При ошибке форма остаётся открытой. Пустые поля можно сохранить — прежнее содержимое останется в истории. Повторная отправка неизменившегося текста с актуальной версией не создаёт лишней записи. Итоги не создают задач и не меняют версии распознавания. JSON-экспорт включает manual_notes, история доступна отдельной командой.

Пять дополнительных тестов проверяют устойчивое сохранение, аудит, конфликт двух соединений, отделение демо от реальных данных, ограничения размера, происхождение автора, очистку с сохранением истории и обновление схемы 13 → 14. В браузере проверены добавление и reload на изолированной базе. Аппаратная запись повторно не запускалась.
