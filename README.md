# VTASK и Валли

VTASK для macOS связывает совещания, проекты, задачи и решения. Приложение на SwiftUI и вспомогательная локальная веб-панель работают через общее ядро Rust и базу SQLite. Основной интерфейс этой версии — приложение macOS.

Версия `0.2.0-rc.3` находится в ветке `feature/analyst-roadmap`. [Журнал версий](CHANGELOG.md) · [План разработки](ROADMAP.md) · [Справка пользователя](native/macos/Sources/VTASK/Resources/VTASK-user-guide.html)

## Возможности приложения

| Раздел | Что доступно |
| --- | --- |
| **Сегодня** | Поиск по задачам, проектам и совещаниям через ⌘K. Показатели просрочек, ближайших сроков, активных задач и проектов открывают соответствующие выборки. В фокусе — личные задачи, задачи по проектам и проблемные задачи. Есть календарь, диаграмма Ганта, графики сроков и нагрузки, уведомления и переход к согласованию. |
| **Проекты** | Актуальные, все, избранные и архивные проекты. Поиск, фильтры, карточки и список, сортировка по обновлению, названию или сроку. В обзоре доступны прогресс, критические задачи, сроки, команда, вехи и риски. В карточке можно редактировать описание, цель, ответственного, участников, материалы, даты и словари, открывать задачи, решения и совещания. Архивные проекты и их задачи исключаются из обычных рабочих выборок. |
| **Задачи и решения** | Список с фильтрами по проекту, статусу, исполнителю, сроку и приоритету, группировка по темам, доска и календарь. У задачи есть исполнитель, срок с необязательным временем, статус, приоритет, блокировка, зависимости в проекте, история и ссылки на источник. Решение фиксирует договорённость и может быть связано с задачами. |
| **Доска** | Карточки перетаскиваются между статусами внутри проекта. Колонки можно добавлять, переименовывать, переставлять и удалять. При удалении занятой колонки выбирается статус для переноса её задач. |
| **Согласование** | Новые поручения, решения и предложения изменить дату, исполнителя, статус или блокировку видны в разделе «На согласовании». Можно сверить старое и предлагаемое значения, открыть исходную реплику, уточнить поля, выбрать связанную задачу, подтвердить или отклонить предложение. Доступны пакетные действия. |
| **Совещания** | Список и календарь с поиском и фильтрами по проекту, участнику и периоду. Карточка встречи хранит дату, участников, аудио и протокол. Запись запускается вручную, поддерживает паузу, остановку и продолжение той же встречи. Можно импортировать аудио и отслеживать или прерывать обработку. |
| **Протокол и анализ** | Редактирование и прослушивание реплик, сопоставление говорящих, итоги, открытые вопросы, решения и задачи. Анализ учитывает контекст проекта и источники в протоколе. Задачи и решения можно группировать по темам. Метка «Нет в справочнике этапов» появляется, если локальное сопоставление не нашло похожего этапа. |
| **Участники** | Поиск и фильтры по справочнику. Карточка хранит ФИО, псевдоним, контакты, подразделение, роль и фото. Голосовой образец можно записать по подсказкам, загрузить из файла или собрать из вручную назначенных реплик совещания. |
| **Справочники** | Готовые отраслевые словари и словарь компании с терминами, вариантами и сокращениями. Кандидатов из анализа можно подтвердить, объединить с термином или отклонить. Есть импорт и экспорт JSON. Этапы работ редактируются отдельно, включая независимые списки «Декор» и «События». |
| **Валли** | Чат принимает текст и голос. Валли ищет задачи, проекты и встречи, уточняет неоднозначные запросы, открывает карточки, заполняет черновики и подготавливает изменения. Обучение запускается кнопкой «Обучение» в окне Валли. |
| **Настройки** | Светлая, тёмная или системная тема, выбор отрасли, микрофона, движка речи, модели анализа и голоса ответов Валли. Профили для команд, полного анализа и предварительного анализа настраиваются отдельно. |

### Этапы работ, темы и статусы

- **Этап проекта** — именованный период с датами. При добавлении из справочника название копируется в проект. Редактирование шаблона и редактирование уже добавленного этапа выполняются отдельно, в том числе для архивных проектов.
- **Тема протокола** — группа по смыслу разговора. Её предлагает анализ, а локальные правила и словарь уточняют группировку. Подсветка отсутствующего этапа работает в интерфейсе и не отправляет отдельный запрос к ИИ.
- **Статус задачи** — колонка доски, например «В работе» или «На проверке». Порядок колонок задаётся для конкретного проекта. Перемещение карточки обновляет статус задачи.

## Как пройти путь от встречи до задачи

1. Создайте проект и карточки участников. В проекте выберите словарь при необходимости.
2. Создайте встречу и нажмите кнопку записи в её карточке. Дайте macOS доступ к микрофону при первом использовании.
3. Завершите запись. Распознавание можно запустить вручную или включить автоматически. В разделе «Обработка» видны этапы и состояние задания.
4. Проверьте расшифровку. При необходимости прослушайте реплики, исправьте текст и назначьте говорящих. Сохранённые голосовые профили доступны при сопоставлении на дальнейших встречах.
5. Запустите анализ протокола. Проверьте резюме, открытые вопросы и предложения в «Задачи и решения → На согласовании». В карточке предложения можно сверить источник и выбрать правильную задачу для изменения.

## Примеры команд Валли

| Что сказать или написать | Что делает VTASK |
| --- | --- |
| «Покажи задачи на неделю» | Показывает задачи по сроку. Отменённые задачи включаются по явному запросу. |
| «Покажи задачи по закупкам» | Ищет по названию, описанию и связанному контексту. В карточке проекта учитывает текущий проект. |
| «По исполнителю Алексей» | Уточняет предыдущую выборку задач. |
| «Открой последнее совещание» | В контексте проекта открывает встречу с самой поздней датой. |
| «Создай задачу заказать образцы» | Открывает черновик, заполняет распознанные поля и уточняет недостающие. Карточку можно сохранить или отменить. |
| «Перенеси срок на завтра в 16:30» | В контексте задачи готовит предложение по сроку. |
| «Под сотиком я имел в виду сотовый поликарбонат» | Предлагает запись для словаря компании. |

При включённом Live Валли показывает предварительный текст. Для голосовой команды во время записи нажмите микрофон в чате, произнесите команду и остановите захват команды. Проверьте получившийся текст перед отправкой. [Подробный справочник Валли](docs/wally-capabilities.md)

## Распознавание и ИИ

- **Расшифровка аудио.** Основной локальный путь использует Whisper. Запись и распознавание запускаются независимо. Для локального разделения и сопоставления голосов требуются установленные модели и адаптеры.
- **Голос Валли.** Движок распознавания команд выбирается отдельно. Доступны системное распознавание macOS, Whisper и SpeechAnalyzer при поддерживаемой версии системы. SpeechAnalyzer требует macOS 26 и установленного языкового ресурса. Озвучивание использует доступный локальный или системный голос.
- **Анализ текста.** В настройках доступны Ollama с локальным Qwen и профили Groq, DeepSeek, OpenAI, Anthropic, Google Gemini и Mistral. При выборе облачного профиля провайдер получает подготовленный контекст соответствующей операции. Дневной и месячный лимиты относятся к облачным запросам.
- **Терминология.** Подходящие записи выбираются локально из словаря компании и нужных отраслей. Кандидаты в термины извлекаются из штатного анализа. Загрузка всей базы словарей в запрос и отдельный запрос для поиска кандидатов не требуются.

## Сборка и запуск

Из корня репозитория на Mac с Rust и Xcode Command Line Tools:

```sh
bash scripts/setup-macos.sh --with-microphone
bash scripts/build-macos-app.sh
open native/macos/.build/VTASK.app
```

Для запуска локальной веб-панели после подготовки окружения:

```sh
bash scripts/start-macos.sh --db "$HOME/Library/Application Support/VTracker/data.sqlite3"
```

Адрес веб-панели — `http://127.0.0.1:8765`. Если нужны только запись и управление данными, для подготовки окружения есть режим `bash scripts/setup-macos.sh --recording-only`. [Установка и проверка на Mac](docs/mac-testing.md) · [Веб-панель](docs/web-panel.md)

По умолчанию SQLite хранится в `~/Library/Application Support/VTracker/data.sqlite3`. Для резервной копии сохраняйте базу вместе со связанными аудиофайлами и голосовыми данными. Рабочая база и пользовательские записи хранятся отдельно от репозитория.

## Для разработки

- `native/macos/` содержит интерфейс SwiftUI и адаптер захвата.
- `src/` содержит ядро, локальный HTTP API, обработчики речи, словарей и операций рабочей области.
- `migrations/` содержит миграции SQLite. `web/` содержит вспомогательную веб-панель.
- `scripts/` содержит сборку, настройку моделей и сценарии проверки. Для отдельной офлайн-сборки macOS есть `scripts/build-macos-offline-dmg.sh` с собственными требованиями к комплекту ресурсов.

```sh
cargo test --locked
```
