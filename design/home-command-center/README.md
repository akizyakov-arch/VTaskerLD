# VTasker — Главная / центр управления

Это **интерактивный визуальный прототип**, а не новая реализация рабочего экрана.

## Открыть

Откройте `index.html` локально в браузере или запустите статический сервер в этой папке.

## Принцип UX

Главная = рабочий центр принятия решений, а не отчётная панель.

1. **Сигналы внимания:** проблемные задачи, ближайшие сроки, активные задачи и проекты.
2. **Фокус сегодня:** единый список с фильтрами, выделением просрочек и задач без исполнителя.
3. **Проекты:** быстрый обзор прогресса и проблем.
4. **Ближайшие сроки:** компактный список вместо большого календаря.
5. **Vally:** предложения на подтверждение — никакого скрытого изменения задач.
6. **Быстрые действия:** вход в создание задач, встреч и проектов.

## Интерактивность макета

- Переключение вкладок и фильтров задач.
- Завершение демонстрационной задачи по чекбоксу.
- Счётчик проблемных задач пересчитывается.
- Сводные карточки переключают фильтры или прокручивают к проектам.
- «Позже» скрывает предложение Vally.
- Остальные действия отмечены как точки будущей интеграции.

## Для разработчика

- Не заменять существующий SwiftUI/web интерфейс автоматически.
- Подставить реальные данные из существующих проектов, задач, решений и встреч.
- Сохранять фильтры между переходами, как в существующей модели навигации.
- Обрабатывать карточки предупреждений по фактическому статусу задачи и сроку, не по искусственному числу.
- Кнопка Vally должна открывать **подтверждение предложений**, а не выполнять изменения без согласия.
- Поддержать клавиатуру, VoiceOver, светлую и тёмную темы.
- Никаких backend / API изменений эта ветка не делает.

## Статус

Дизайн-демо, данные вымышленные и не синхронизируются с приложением.
